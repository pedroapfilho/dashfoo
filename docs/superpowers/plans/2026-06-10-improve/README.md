## Findings considered and rejected (do not re-audit)

- **Per-frame `adjustSplit` burst during splitter drags** — disproven: rrp v4
  commits one `adjustSplit` per release (code comment in
  `packages/core/src/state/history.ts:6-8`; empirically, the e2e
  "undo and redo restore resized panel dimensions" restores pre-drag width with
  a single undo).
- **Add `React.memo` to TabsetView/RowView** — ineffective as proposed: the
  reducer `structuredClone`s the whole model per action, so every node gets a
  fresh identity and views consume a rebuilt context; memo alone changes
  nothing. The real fix is structural sharing in the reducer — unjustified
  today because model changes are event-cadence, not frame-cadence (only the
  one-div DockIndicator renders per-frame). Revisit only if profiling shows
  jank on large layouts.
- **`memoryStorageAdapter` factory vs `localStorageAdapter` singleton** — by
  design (isolated map per instance vs inherently global localStorage);
  documented in the persistence guide.
- **`tabRects`/`tabItemRects` "duplication"** — intentional: they query
  different selectors (`tab` vs `tab-item`) for different geometry (insertion
  index vs insertion line).
- **zod validation cost at drag start** — negligible; one small-object parse
  per drag initiation.
- **Turbo remote cache** — needs external infrastructure/tokens; revisit when
  CI time actually hurts.
- **postcss moderate advisory (`pnpm audit`)** — transitive via Next/fumadocs
  in the docs app only; rides the next framework bump.
- **Persisted-layout migration hook (direction A)** — REJECTED by maintainer
  policy above: pre-adoption, the schema may break freely; stored-layout
  validation failure falling back to `defaultModel` is acceptable until there
  are real users.
- **Direction B (keyboard docking spike), C (drag-out/floating panels), D
  (responsive demo page)** — not selected this round. B and C are the strongest
  v1.1 candidates (B: a11y gap acknowledged in commit `8c9975b`; C: README
  scopes popout out of v1). D was a deliberate demo-scope decision on
  2026-06-10.

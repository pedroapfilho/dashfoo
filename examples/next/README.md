# Dashfoo Next starter

Copy this directory outside the monorepo, then run:

```sh
npm install
npm run dev
# or: pnpm install && pnpm dev
```

Run `npm run build` (or `pnpm build`) to validate the production build.
The layout is saved in this browser. Notes survive tab switches through
`keepMounted`, but widget content is not part of the saved layout.
React 18.3 is also supported by the Vite starter; Next.js uses React 19.
